Privacy policy

Last updated: 26 November 2026

whatif-upload is used only by its owner. It uses YouTube API Services with the single permission to upload videos (youtube.upload) to the owner's channel.

It does not collect, read, sell or share personal data. The OAuth token is stored as an encrypted GitHub Actions secret and is used only to upload videos. The IDs of uploaded videos are stored in a private repository to avoid duplicates.

Access can be revoked at any time at Google account permissions; deleting the repository secrets removes the stored token.

By using YouTube API Services, the tool is bound by the YouTube Terms of Service. See the Google Privacy Policy.
